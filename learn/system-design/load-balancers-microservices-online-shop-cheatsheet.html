The pictures to draw on the whiteboard. Practice sketching each in under 30 seconds.

1 · Where the load balancer sits

Say this: "Clients only ever see the LB. It terminates TLS, health-checks the fleet, and because the app tier is stateless — sessions in JWT or Redis — any instance can serve any request."

2 · L4 vs L7 — what each one sees

Say this: "L4 forwards connections by IP and port — fast but content-blind. L7 terminates HTTP and routes on path or headers. Web apps default to L7; big systems chain L4 in front of L7, like GitHub's GLB."

3 · Rolling deploy with connection draining

Say this: "New instance only gets traffic after health checks pass; the old one drains — no new requests, in-flight ones finish. That's zero-downtime. ALB's default drain is 300 seconds; I'd set 30–60."

4 · The online shop — modular monolith + extracted services

Say this: "One modular monolith for catalog, cart, users, orders, inventory — real ACID on one Postgres. I extract only payments (isolation, PCI, third-party coupling) and async workers. Extract more when a boundary proves itself, not by default."

5 · Payment webhook — the money flow

Say this: "The webhook is the source of truth, not the client redirect. Verify, Dedupe, Queue, Ack — delivery is at-least-once, so processing must be idempotent."

One snippet to remember: the Stripe webhook handler. It encodes Verify → Dedupe → Queue → Ack.

app.post("/webhooks/stripe",
  express.raw({ type: "application/json" }),        // raw body BEFORE json()
  async (req, res) => {
    const event = stripe.webhooks.constructEvent(   // 1. VERIFY signature
      req.body, req.headers["stripe-signature"]!, WEBHOOK_SECRET
    );
    const seen = await prisma.processedEvent.findUnique({
      where: { id: event.id },
    });
    if (!seen) {                                    // 2. DEDUPE (at-least-once!)
      await prisma.processedEvent.create({ data: { id: event.id } });
      await queue.add("stripe-event", event);       // 3. QUEUE the heavy work
    }
    res.sendStatus(200);                            // 4. ACK fast
  });
How to talk about it: "Signature verification needs the raw body, so express.raw() goes on this route only. Stripe delivers at-least-once and retries for 3 days, so I dedupe on event.id and return 200 immediately — the actual order update runs in a BullMQ worker with retries. The charge itself was created with an Idempotency-Key derived from the order ID, so a double-click can't double-charge."
