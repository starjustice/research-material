LLM features in a system: RAG, a gateway, an injected page, and streaming

No real model is called here. The search and the gateway run the same code as the practice file. The model is a pretend model, so every step is the same each time. Times are example numbers, not measured.

setup

The rule to remember: the model is a slow, costly service that can be wrong and can be fooled. Your code finds the facts, a gateway guards the call, the answer streams to the user, and your code checks everything that comes back before it acts.
