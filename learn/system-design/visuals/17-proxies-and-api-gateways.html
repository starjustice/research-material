Proxies and API gateways: one door, one copy or two, and a BFF

Press Next and watch one request at a time. Guess first, then check. All numbers in stories 2 and 3 are example numbers, not measured.

setup

The rule to remember: the gateway is the one public door. It checks the ticket, checks the limit, picks the service, and does nothing else. It is also the one door, so run two copies of it. A BFF is a small server for one kind of app. It shapes data, and it holds no business rules.
