Safe deploys: a canary, blue green, a feature flag, and a column rename

Use the buttons below to move one step at a time. Guess first, then check. All times and traffic numbers are example numbers.

setup

The rule to remember: never let one release touch every user at once without a way back. A canary shows it to a few users first. Blue green keeps the old copy running. A feature flag separates deploying from releasing. Expand and contract changes the database in small steps that each work with old and new code.
