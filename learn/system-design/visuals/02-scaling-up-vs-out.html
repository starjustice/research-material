Scaling out: why servers must keep no user data

Press Next and watch one user, one load balancer and a few servers. One step is one thing that happens to a request.

Sam's browser

Browser

keeps a cookie, a small note it sends with every request

Front door

Load balancer

sends each request to one server, taking turns

Your servers

Shared box

a database or Redis. Every server can reach it.
setup

The rule to remember: a server may only keep what it can lose. Anything a later request needs goes in the shared box. Then any server can answer any request, and you can add or remove servers at any time.
