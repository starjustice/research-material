The rule to remember: save first, then ack, then deliver. A Redis map says which server each phone is on. An offline phone gets a push, then asks for everything after its last id. A resend with the same clientMsgId is saved only once. Ticks: ✓ saved, ✓✓ delivered, blue ✓✓ read.
