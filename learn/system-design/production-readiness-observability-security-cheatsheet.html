See it · Measure it · Ship it safely · Protect it · Survive it · Pay for it

The last 5 minutes of a design round. Redraw each picture from memory.

1 · One request, one name tag (trace id)

Say this: "Every request gets a trace id at the edge. It rides in the traceparent header over HTTP and inside the job data through the queue. Every JSON log line carries it, so one search shows the whole path."

2 · Why averages lie

Say this: "I alert on p95 and p99, not the average. The average mixes fast and slow users into a number nobody felt, and slow tails add up when one page calls many services."

3 · The error budget and burn rate

Say this: "99.9% over 30 days leaves about 43 minutes. I page on fast budget burn, a symptom users feel, not on CPU, which is a cause."

4 · Canary deploy with automatic rollback

Say this: "I deploy as a canary and roll back automatically if errors or p99 get worse. Risky features sit behind a flag, so release is separate from deploy."

5 · Four disaster recovery plans

Say this: "I ask the business for RPO and RTO first, then pick the cheapest plan that meets them. A replica is not a backup, and a backup is only real after a restore drill."

6 · A security check at every arrow

Say this: "The gateway checks the token is real. Each service checks this user may touch this object, which stops BOLA, the number one OWASP API risk. Services prove who they are with mTLS or short lived tokens."

7 · A rough monthly bill, out loud

Say this: "At this scale the bill is mostly egress, logs and the database. A CDN, log sampling with short retention, and keeping app and DB in one zone are my first three levers."
