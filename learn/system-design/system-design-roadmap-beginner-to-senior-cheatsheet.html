SYSTEM DESIGN ROADMAP

Six layers · Six stages · The seven steps · Mid vs senior · The 10 week plan

Redraw each picture from memory before you start a new stage.

1 · Every system has six layers

Say this: "I think about a system in layers: the screen, the network, the API, the data, the work done later, and how we keep it running. Each layer has its own failure points."

2 · The six stages, in order

Say this to yourself: "Parts first, then the method, then correctness, then running it. Practice from Stage 2 on, every week."

3 · The seven steps of a design round (45 minutes)

Say this: "Before I draw, let me agree on what we are building and how big it is. Then the API and the data, then the boxes, then the hard part, then what breaks."

4 · The same idea, said two ways

Say this to yourself: "Every choice gets a number, a reason, a cost, and what happens when it fails."

5 · Your week

Say this to yourself: "Read one thing, draw one thing, say one thing. Every week."

Tick ✓ only when you can do it with the notes closed. The number shows the stage.
