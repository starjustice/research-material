The rule to remember: every call gets a new scope box and goes on top of the call stack. The arguments go into the parameter slots of that box. When the call gives back its value, it leaves the stack and its box is thrown away.

    
Words on this page:

    
    
      
  • Call stack: the list of calls that are running now. A new call goes on top. A call leaves when it is done. The calls below the top one are paused and wait.
    • 
      
  • Scope box: the place in memory where the names of one call live. Every call makes a new one. (Interview word: execution context or environment.)
    • 
      
  • Slot: one named place inside a box that holds one value.
    • 
      
  • Locked: a let or const slot before its line runs. Reading it is a ReferenceError. (Lesson 01.)
    • 
      
  • Parameter: a name in the brackets where you write the function, like name. Argument: the value you pass in the call, like "Ana".
    • 
      
  • Missing: x = undefined missing means no argument came in for this parameter.
    • 
      
  • Return value: the value a call gives back. Shown as ↩ gives back 5. With no return, it is undefined.
    • 
      
  • ƒ means the slot holds a function. hello = ƒ sayHi means "the slot hello points at the function called sayHi". Two slots can point at the same function. It is not copied.
    • 
      
  • Outer link: where JavaScript looks next if a name is not in this box. It is the box where the function was written. Lesson 05 (closures) is all about this link.
    • 
    

    
The labels G, C1, C2 are only names added on this page so you can follow the boxes. In real JavaScript the memory of a finished box is freed a little later, by the cleaner (the garbage collector).
