The rule to remember: this is decided by the call, not by where the function is written. Ask in this order: 1 new, 2 call, apply or bind, 3 a dot call (obj.fn()), 4 a plain call (undefined in strict mode, globalThis in sloppy mode). Arrow functions skip all four and borrow this from the code around them. You can open one program directly, for example #5 for call, apply and bind, or #2.4 for program 2, step 4.
