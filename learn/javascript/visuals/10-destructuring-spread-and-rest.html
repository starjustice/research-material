The rule to remember: the same three dots, opposite directions. On the left side (a pattern, or a function's parameter list), ... is rest: it collects the leftovers into one new array or object, and it must be last. On the right side (inside a call, inside [ ] or inside { }), ... is spread: it expands one value into separate pieces. A default applies only to undefined. Spread copies only one level.

  
Words on this page: a pattern is the [ ] or { } on the left of = that says which values go into which variables. A default is the value after = inside a pattern, used when the value is missing. A shallow copy copies only the top level, so objects inside are shared.
