    The rule to remember: === never changes a type. If the types are different, the answer is false. == walks down the checklist and changes one side at a time until both sides have the same type. An if does not use the checklist at all. It only asks: is this value on the short list of values that count as false?
    
  
    Words on this page: a simple value is one plain value like 5, "2" or true (interview word: primitive). An object is a value with parts, like {}, [] or a function. A string is text. A boolean is true or false. Changing the type on its own is called coercion. A round is one pass down the checklist.
