The rule to remember: = copies what is in the slot. For a simple value (a number, text, true or false), the value itself is in the slot, so you get your own copy. For an object (and arrays are objects), the slot holds an arrow, so you get a second arrow to the same object. === on two objects only asks: do the arrows point at the same object?

  
Words on this page: a simple value is a number, text, true, false, null or undefined (interview word: primitive). An arrow is what a variable holds when its value is an object (interview word: reference). A change in place changes the inside of an object that already exists (interview word: mutate). A shallow copy makes one new outer object, but the objects inside are still shared. A deep copy makes every level new. The cleaner frees an object when nothing points at it any more (interview word: garbage collector).
