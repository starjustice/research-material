The rule to remember: a function carries a link to the scope box where it was created. A scope box is kept for as long as something points at it: a running call, a function, or a waiting callback. When nothing points at it, it can be freed.

    
How to read the colors: G is the Global box. S1, S2 and S3 are boxes made by the outer function (or by a loop pass). Gray boxes are the short boxes made for one call. The labels G, S1, S2 are only names I added so you can follow the links. A pill like link → S1 means "this function carries a link to box S1".

    
A box with no function pointing at it, like a finished call box, disappears at once in this page. In a real engine the memory is freed a little later, at a time the garbage collector chooses.
