Use the buttons below to move one step at a time. Guess first, then check. The numbers come from a real run of a small stack (a Node web app, Postgres 17 and Redis 7) on Docker Compose v5.1.1, on 2026-11-13.

The rule to remember: depends_on waits for running, not for ready. A healthcheck plus service_healthy waits for ready. Services find each other by service name, and localhost is only yourself. Only down -v deletes a named volume.
