Serverless: cold starts, scale to zero, limits and the bill

Use the buttons below to move one step at a time. Guess first, then check. Stories 1 to 3 run the same model as the lesson practice, with example numbers (not a real platform). Story 4 uses the AWS Lambda price list checked on 2026-11-13.

setup

The rule to remember: a function runs in a copy that the platform starts when needed and removes when idle. The first call on a new copy is cold and slow. Later calls on the same copy are warm and fast. You pay for the work, so serverless is cheap for low or bursty traffic, and a fixed server can be cheaper for steady high traffic.
