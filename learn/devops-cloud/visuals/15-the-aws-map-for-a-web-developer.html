The rule to remember: a web app is a few small pieces, each with one job. Route 53 finds you, CloudFront keeps copies near the users, a load balancer shares the work, your code runs on Fargate (or Lambda, or EC2), S3 keeps files and RDS keeps the data. Pick by who looks after the machine.
