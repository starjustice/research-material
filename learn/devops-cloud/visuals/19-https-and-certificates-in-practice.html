HTTPS and certificates: get one, check one, end it at the proxy, renew it

Use the buttons below to move one step at a time. Guess first, then check. This is a small model. It runs the same challengeFor, verifyChain, renewalStatus, hstsHeader, maxLifetimeDays and legs code as the practice answer in the lesson. Nothing here talks to a real certificate authority. The names, addresses and dates are made up for the story. The 90, 45 and 6 day lengths and the date rules are real (see the lesson).

setup

The rule to remember: a certificate proves who controls a name. The browser trusts it through a chain up to a root it already knows. The proxy ends the HTTPS, so the last leg is plain unless you encrypt it again. Certificates are getting shorter, so renewal must be automatic and watched. HSTS removes the click through, so a missed renewal is a full outage.
