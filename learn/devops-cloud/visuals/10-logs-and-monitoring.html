Logs and monitoring: log rotation, one request, an alert, a health check

Use the buttons below to move one step at a time. Guess first, then check. Stories 2, 3 and 4 use lines and numbers from a real test on Docker Desktop 29.3.1 (2026-11-13). In story 1 the file sizes are made small on purpose, so you can see the rotation.

setup

The rule to remember: write logs to stdout, one JSON line each, with a level and a request id. Tell Docker to keep only the newest files. Let a health check report the state, and let something else act on it. And check the site from outside, because only that sees what your users see.
