VPC networking: a request in, a call out through NAT, two firewalls, two locks

Use the buttons below to move one step at a time. Guess first, then check. This is a small model of an AWS VPC. It runs the same pickRoute, isPublicSubnet, sgAllowsInbound, naclAllows, roundTrip, internetAccess and natCost code as the practice answer in the lesson. Nothing here talks to a real cloud. The addresses are made up (they come from ranges that are kept for examples). The model shows one zone only. A real setup repeats the boxes in a second zone.

setup

The rule to remember: a subnet is public only because its route table has a road to the internet gateway. A security group is a guard that remembers connections. A network ACL is a guard with no memory. A NAT gateway lets private servers call out, and lets nobody call in. Keep the database in a private subnet: no road in, and no rule that lets strangers in.
