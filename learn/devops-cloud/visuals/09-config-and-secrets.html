Config and secrets: a secret in a layer, the config order, build time vs run time, logs

Use the buttons below to move one step at a time. Guess first, then check. The image layers, the Next.js answers and the build output come from real runs (Docker Desktop 29.3.1, Next.js 16.4.6, 2026-11-13). Every secret here is the made up text not-a-real-secret.

setup

The rule to remember: keep settings out of the code and out of the image. Deleting a secret in a later layer only hides it. A NEXT_PUBLIC_ value is pasted into the code at build time, so it is public and frozen. Give a secret to a container when it starts, as a file, and hide it in logs.
