Container and supply chain security: where an attack can enter

Use the buttons below to move one step at a time. Guess first, then check. This is a small model. It runs the same lintDockerfile, verifyDeploy, cooldownOk, scan and gate code as the practice answer in the lesson. Nothing here talks to npm, Docker, Trivy or cosign. The package name tiny-logger and the advisory ids are made up.

setup

The rule to remember: you cannot stop an attacker from publishing a bad version. You can make every later step refuse to trust it: exact versions, install scripts off, a short wait, a pinned small image, a scan, a signature checked at the door, and an app that is not root.
