Cloud cost basics: one month of a bill, line by line

Use the buttons below to move one step at a time. Guess first, then check. A small shop app runs on AWS for one month. The page adds up its bill with the same estimateBill, cheaperOption, forecastMonth, firstAlertDay and costByTag code as the practice answer in the lesson. The prices are examples: AWS, US East (N. Virginia), read from the AWS price list on 2026-11-19. The amounts of traffic and storage are made up. Prices change, so check the current ones before you decide anything.

setup

The rule to remember: a bill is many small meters. Some count hours (a thing that exists), some count GB moved, some count GB stored. First delete what you do not use, then use less, then pay less per hour, and promise a year only at the end. Set a budget alert and tag everything, so you see a jump in days and not at the end of the month.
