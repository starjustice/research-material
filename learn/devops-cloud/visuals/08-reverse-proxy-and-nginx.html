Reverse proxy and Nginx: one request, the rules, a pool of apps, and the headers

Use the buttons below to move one step at a time. Guess first, then check. The outputs come from real nginx 1.30.6 runs in Docker, and the steps run the same code as the practice answer. Steps that come from the model only say so.

The rule to remember: nginx picks the server by the Host header, the location by the longest prefix, and then sends the request to one app in the pool. The app only talks to nginx, so pass the host and the client address in headers. No app up means 502.
