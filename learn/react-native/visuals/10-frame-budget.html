The frame budget: who draws while JavaScript is busy?

A phone draws about 60 frames each second, so one frame has about 16 ms. In every tab a 100 ms job blocks the JavaScript thread. Press Next and see what the user sees. The 100 ms is an example, not a measurement.

Predict first. A 100 ms job blocks the JavaScript thread. Which of these still moves smoothly? (a) a box moved by setState on every frame, (b) a box moved with useNativeDriver: true, (c) dragging a ScrollView.

The rule to remember: Work that needs JavaScript on every frame stutters when JavaScript is busy. Work that the UI thread can do alone keeps going. Move animations to the UI thread and keep the JavaScript thread free.
