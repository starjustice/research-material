ScrollView or FlatList: who is mounted?

A list of 1000 rows, each 50 tall, on a screen 800 tall (16 rows fit). Pick a tab, press Next. The numbers come from a small model that uses the documented defaults (windowSize 21, initialNumToRender 10, 10 rows per batch every 50 ms).

Predict first. The list has 1000 rows and the user sees 16. About how many rows does a FlatList keep mounted when the user is in the middle: 16, about 350, or 1000?

The rule to remember: A ScrollView mounts every row. A FlatList mounts the rows near the screen, and the rest are only data. The price is a blank area if you scroll faster than it can fill.
