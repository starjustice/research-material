HTTP/1.1, HTTP/2 and HTTP/3: lines, one road, a lost packet

Use the buttons below to move one step at a time. Guess first, then check. This is a small model. It runs the same h1Schedule, h2LoadTime, deliveryTimes, pickProtocol, parseAltSvc, setupRoundTrips and survivesNetworkChange as the practice answer in the lesson. No real network is used.

setup

The rule to remember: HTTP/1.1 does one request per connection, so browsers open six. HTTP/2 shares one connection, but TCP holds every stream when one packet is lost. HTTP/3 uses QUIC, so only the stream with the loss waits.
