Cookies, CORS and same origin: who may send, who may read

Use the buttons below to move one step at a time. Guess first, then check. This is a small model. It runs the same originOf, sameOrigin, sameSite, needsPreflight, corsHeaders, checkCors, browserFetch, setCookieHeader and cookieSent as the practice answer. No real browser is used here.

setup

The rule to remember: an origin is scheme + host + port. The browser blocks your JavaScript from reading a cross-origin answer unless the server sends permission headers. The server still runs the request. SameSite decides if the cookie is sent. CORS is not a defense against CSRF.
