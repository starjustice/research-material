TCP vs UDP: handshake, resend, order, closing and windows

Press Next to move one step. Guess first, then check. Everything runs on a small model: the same code as the lesson practice answer. Nothing here is a real network, and the numbers are examples.

setup

The rule to remember: IP only tries its best. TCP adds a handshake, numbers, receipts and resending, so every byte arrives in order, but it can arrive late. UDP adds almost nothing: no handshake, no resend, no order. Pick TCP when every byte matters. Pick UDP when old data is useless.
