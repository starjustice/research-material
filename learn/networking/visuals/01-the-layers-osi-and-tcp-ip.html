The layers: wrap, hop, drop, balance

Use the buttons below to move one step at a time. Guess first, then check. This is a small model of how a request is wrapped in headers, passed on by a router, and read by a server or a load balancer. It runs the same encapsulate, decapsulate, routerForward, wireBytes, routeKey and canSeePath code as the practice answer in the lesson. Nothing here uses a real network. The addresses are made up.

setup

The rule to remember: going down, each layer adds one header (ports, then IP addresses, then MAC addresses). A MAC names the next stop, an IP names the machine, a port names the program. A load balancer is called layer 4 or layer 7 by how deep it reads.
