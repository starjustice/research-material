The rule to remember: a cache is a fast copy in front of the database. It makes reads cheap and can be out of date. Cache what is read often and can be a little old. Never decide a write from it.

    
Words on this page:

    
    
      
  • Cache-aside: look in the cache, on a miss ask the database, keep the answer.
    • 
      
  • Hit / miss: the key is in the cache / it is not.
    • 
      
  • Time to live (TTL): how long a cached answer may stay.
    • 
      
  • Stale: the cache still has an old answer.
    • 
      
  • Stampede: many requests miss at the same moment and all hit the database.
