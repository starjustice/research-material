The rule to remember: save each fact in one place. A store's city belongs on the store row, not on every order. Copy a fact only on purpose, and then decide who keeps the copy right.

    
How to read the colors:
      orange the same fact saved again (a duplicate).
      yellow the cell the statement just changed.
      red a wrong answer, an error, or a row that is gone.
      green a new row, or a right answer.

    
Words on this page: duplicate: the same fact saved in more than one row (interview word: redundancy). problem when you change, add or delete: what a duplicate breaks (interview words: update, insert and delete anomaly). split: move a repeated fact to its own table and point at it with an id (interview word: normalize). copy on purpose: save a fact twice to freeze it or to read it fast (interview word: denormalize).

    
Every result on this page comes from a real run on PostgreSQL 18.3 (PGlite) on 2026-10-16. The tables live in a schema called l07, so they never touch the practice tables.
