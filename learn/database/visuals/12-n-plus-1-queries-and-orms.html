The rule to remember: count the trips, not the speed of one query. A loop that sends one query per row makes 1 + N trips. Ask for all the rows in one go (a JOIN, or = ANY($1) with all the ids), then sort them into place in your code.

    
Words on this page:

    
    
      
  • Trip: the app sends one query and waits for the answer. (Interview word: round trip.)
    • 
      
  • N+1: 1 query for the list, then N more queries, one for each item in the list.
    • 
      
  • Batch: many small requests packed into one query.
    • 
      
  • Tick: one turn of JavaScript running code before it looks at its waiting callbacks. DataLoader collects keys during one tick.
