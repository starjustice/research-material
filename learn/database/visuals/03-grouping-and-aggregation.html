The rule to remember: WHERE throws away rows before they reach a bucket. HAVING throws away buckets after every row is in. A join that makes copies of a row makes every SUM count that row again, so add up each table first and join after.

  
Words on this page
    
    
      
  • Bucket: all rows with the same value in the GROUP BY column. Interview word: group.
    • 
      
  • Summary function: COUNT, SUM, AVG, MIN or MAX. It reads many rows and gives one value per bucket. Interview word: aggregate function.
    • 
      
  • Running total: the number Postgres keeps for each bucket and changes as each row arrives.
    • 
      
  • NULL: an empty cell. COUNT(column) skips it. COUNT(*) does not.
    • 
      
  • Fan-out: a join that turns one row into many copies.
