The rule to remember: a connection is a process on the server. Keep a few open, lend them out, and make sure instances × pool size stays under max_connections.

    
Words on this page:

    
    
      
  • Pool: connections kept open and lent out one at a time.
    • 
      
  • max_connections: how many connections the server allows in total (typically 100).
    • 
      
  • connectionTimeoutMillis: how long a request waits for a free connection before it fails.
    • 
      
  • PgBouncer: a pooler between your apps and Postgres. In transaction mode a server connection is lent for one transaction only.
