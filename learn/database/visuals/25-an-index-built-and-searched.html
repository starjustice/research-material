The rule to remember: an index is a short, wide tree of 8 KB pages. A lookup reads the root, a middle page, a leaf, and then one table page: about 4 pages for 1 million rows. Without an index it reads every page.

    
Words on this page:

    
    
      
  • Leaf page: the bottom level of the index. It holds the keys in order, each with the address of its row.
    • 
      
  • Address (ctid): page number and slot number of a row in the table.
    • 
      
  • Visibility map: one mark per table page: "every row here is visible to everyone". VACUUM sets it.
    • 
      
  • Heap Fetches: how many times an index-only scan still had to visit the table.
    • 
      
  • CONCURRENTLY: build an index without blocking writes. Slower, but safe on a live table.
