The rule to remember: a primary key names one row. A foreign key must point at a real row. When the parent is deleted, the default is to refuse.

    
Words on this page:

    
    
      
  • Primary key: unique, never empty, one per table. Postgres builds an index for it.
    • 
      
  • Foreign key: a column that must match a primary key in another table.
    • 
      
  • NO ACTION: the default. Refuse to delete a parent that still has children.
    • 
      
  • CASCADE: delete the children together with the parent.
    • 
      
  • SET NULL: keep the children, and blank their pointer.
