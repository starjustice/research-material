The rule to remember: read the plan from the inside out. The most indented nodes run first, and their rows flow up to their parent. Find the node where rows are thrown away or time piles up. Then compare the guess with the actual rows. A gap of 10 times or more means the planner's notes are old: run ANALYZE.

    
Words on this page:

    
    
      
  • Plan: the recipe Postgres picks for your query. Node: one step of the recipe, one box in the tree.
    • 
      
  • Guess (estimate): the rows the planner expects, before running. Actual: the rows that really came out, from EXPLAIN ANALYZE.
    • 
      
  • Rows removed: rows Postgres read, checked and threw away. A big number is the clue for a missing index.
    • 
      
  • Pages: blocks of 8 kB. The Buffers line counts how many pages a node touched.
    • 
      
  • loops: how many times a node ran. Actual rows are per loop, so multiply.
