The rule to remember: Postgres works in this order: FROM, WHERE, GROUP BY, HAVING, SELECT, ORDER BY, LIMIT. A name you make in SELECT with AS exists only after SELECT. So WHERE cannot use it, but ORDER BY can. WHERE keeps a row only when its test says true. Any = NULL test says unknown, so use IS NULL.

    
Words on this page:

    
    
      
  • Clause: one part of a query that starts with a keyword, like WHERE or ORDER BY.
    • 
      
  • New name (alias): a name you give a column with AS, like total_cents / 100 AS total.
    • 
      
  • NULL: an empty box. Postgres treats it as unknown, not as zero and not as empty text.
    • 
      
  • unknown: the third answer a test can give, next to true and false. WHERE throws away rows that answer unknown.
    • 
    

    
This is the logical order: the order Postgres promises the result matches. The real work can take shortcuts (lesson 11, Reading EXPLAIN), but the answer is always the same.
