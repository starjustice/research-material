The rule to remember: every index is written on every INSERT. An UPDATE that is not HOT writes a new entry in every index. A HOT update needs no indexed column changed, and room on the same page.

    
Words on this page:

    
    
      
  • HOT update: a cheap update. The new row stays on the same page, and no index gets a new entry.
    • 
      
  • fillfactor: how full Postgres fills a page. Lower means more room for HOT updates.
    • 
      
  • Page split: a full index page becomes two pages, and the parent page gets a new entry.
    • 
      
  • VACUUM: removes dead rows and dead index entries so the space can be reused.
