The rule to remember: every program that writes to the table goes through the same gates: DEFAULT fills empty columns, then NOT NULL, then CHECK, then UNIQUE. One refused gate means an ERROR and nothing is saved. The id counter still moves. timestamptz stores one moment in UTC and only shows it in your session time zone.

  
Words on this page: constraint = a rule on a column that Postgres checks on every write. DEFAULT = the value Postgres uses when you leave a column out. UTC = the world's base clock, with no offset. session time zone = a setting on your connection that decides how times are shown. partial unique index = a unique rule that checks only some rows.
