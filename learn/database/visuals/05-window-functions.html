The rule to remember: a window function adds a column and keeps every row. PARTITION BY cuts the rows into separate windows. ORDER BY inside OVER sorts each window. Then Postgres walks down each window and writes one value per row. A new window starts the count again.

  
Words on this page:
    
    
      
  • Window: the group of rows one row is allowed to look at. Here, all orders of the same store.
    • 
      
  • Partition: one window. PARTITION BY store_id makes one window per store.
    • 
      
  • Tie: two rows with the same value in the sort, like two orders of 300.
    • 
      
  • NULL: "no value". Shown here as NULL. psql shows it as an empty cell.
