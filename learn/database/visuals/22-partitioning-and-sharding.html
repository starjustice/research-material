The rule to remember: partitioning splits one table into drawers on one server. A query that names the partition column opens only the drawers it needs. Old data goes away with one DROP.

    
Words on this page:

    
    
      
  • Partition (drawer): one of the smaller tables a partitioned table is stored as.
    • 
      
  • Pruning: leaving out the drawers that cannot hold the rows you asked for.
    • 
      
  • DETACH / DROP: take a drawer out of the table / delete it.
    • 
      
  • Dead rows: deleted rows that still take space until they are cleaned (lesson 16).
