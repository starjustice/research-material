The rule to remember: an UPDATE or DELETE never removes a row. It marks the old version as ended. VACUUM frees the space later, once no transaction can still need it.

    
Words on this page:

    
    
      
  • xmin / xmax: the transaction that created a version, and the one that ended it.
    • 
      
  • ctid: the address of a version: page number and slot number.
    • 
      
  • Dead version: an ended version that no reader can need any more.
    • 
      
  • VACUUM: marks dead space reusable. VACUUM FULL rewrites the table to shrink it, and locks it.
    • 
      
  • idle in transaction: a session that opened a transaction and sends nothing. It can stop VACUUM.
