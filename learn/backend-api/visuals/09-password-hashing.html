The rule to remember: store a one-way, salted, slow hash. Never the password, never encryption, never a fast hash.
  
    
    
  • Hash: a one-way scramble. The same input always gives the same result. You cannot turn it back into the password.
    • 
    
  • Salt: random text, new for each password. It is saved next to the hash. It makes two equal passwords give different hashes.
    • 
    
  • Cost: how slow the hash is on purpose (the interview word is work factor). Slow for one login is fine. Slow for billions of guesses is a wall.
    • 
    
  • Brute force: trying guess after guess until one fits.
