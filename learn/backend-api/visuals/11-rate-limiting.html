The rule to remember: count by who, over a stretch of time, share the count between servers, and answer 429 with Retry-After.
  
    
    
  • Rate limit: the most requests one caller may send in a stretch of time.
    • 
    
  • Key: what you count by. The user id, the IP address or the API key.
    • 
    
  • Window: the stretch of time you count in.
    • 
    
  • Token bucket: a bucket that fills at a steady speed. Each request takes one token.
    • 
  

  Status codes: 200 = allowed. 429 = too many requests, try again later. Retry-After = the number of seconds to wait.
