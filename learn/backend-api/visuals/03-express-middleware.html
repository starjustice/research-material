Express middleware: one request walks the line

Use the buttons below to move one step at a time. Watch the request, the line of functions, and what is on req. Guess first, then check. The steps match the real output of the code in section 4 of the lesson.

setup

The rule to remember: Express runs your functions in the order you added them. Each one must do one of two things: call next() to pass the request on, or send an answer to stop the line. Doing neither makes the request hang. next(err), or a thrown error, skips every normal function and jumps to the error middleware, the function with four parameters, which you add last.
