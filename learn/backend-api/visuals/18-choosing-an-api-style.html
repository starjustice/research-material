The rule to remember: ask who calls, then what they need. Do not start from what is new or fast.
  
    
    
  • REST: a menu of URLs. Best for outside callers and caching.
    • 
    
  • GraphQL: the client picks the fields. Best when different apps want different data.
    • 
    
  • tRPC: typed calls inside one TypeScript repo. Best when both sides ship together.
    • 
    
  • gRPC: fast, typed, binary calls. Best between busy services.
    • 
  

  Words: contract = what you can ask for and what you get. Coupling = how much two sides must change together. Round trip = one trip to the server and back.
