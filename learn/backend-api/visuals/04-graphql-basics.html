GraphQL basics: one query, step by step

Use the buttons below to move one step at a time. Watch the query text, the menu of fields (the schema), the data, and the answer being built. Guess first, then check. Stories 1 to 3 match the real output of the code in section 4 of the lesson.

setup

The rule to remember: the app sends one text, the query, to one URL, POST /graphql. The server first checks every field against the schema. If one field is wrong, nothing runs and the answer has only errors. If all fields are fine, the server runs the functions and sends back data with exactly the fields that were asked, in the same shape as the query.
