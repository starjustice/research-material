The rule to remember: three ways to say yes. A role is one answer for a whole kind of user. A list on the item (ACL) is one answer for one item. A rule on facts (ABAC) is one answer from the facts of this request. Real apps mix them, and the default is always no.
  
    
    
  • ACL: access control list. A list on each item, such as "ana: owner, budi: viewer".
    • 
    
  • ABAC: a rule that reads facts about the user, the thing and the situation.
    • 
    
  • Inheritance: a grant on a folder reaches what is inside it.
    • 
    
  • Scope: a limit written on one token. The token can do the smaller of its scopes and its user's rights.
