The rule to remember: OAuth is permission ("this app may read my files"). OIDC is login, built on OAuth ("this user is 1138"). SAML is company login in XML. An API key is a password for a program.
  
    
    
  • PKCE: the app sends a hash of a secret first, and the secret later. Someone who steals only the one-time code cannot use it.
    • 
    
  • ID token: a signed JWT that says who logged in. Check iss, aud, exp, nonce and the signature.
    • 
    
  • Assertion: the SAML package of statements about a person, in XML and signed.
    • 
    
  • Scope: a limit written on one token or key (lesson 19).
