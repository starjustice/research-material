The rule to remember: a session keeps the facts on the server and gives you a ticket number. A JWT puts the facts in the token and signs it, so the server keeps nothing.
  
    
    
  • Session: a note the server keeps about you. The browser holds only a random id.
    • 
    
  • Cookie: text the browser stores and sends back by itself with every request to that site.
    • 
    
  • JWT: a signed note you carry. It has three parts: header, payload and signature.
    • 
    
  • Signature: a stamp only the server can make. If anyone changes the note, the stamp no longer fits.
