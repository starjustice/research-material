The rule to remember: the types help you while you write code. They are gone when the code runs, so the server must still validate every input and hide unknown errors.
  
    
    
  • RPC: calling a function on another machine as if it were local.
    • 
    
  • Procedure: one function the server offers. A query reads (GET). A mutation changes (POST).
    • 
    
  • Router: a named group of procedures, like a folder.
    • 
    
  • End-to-end types: the client imports the router's type, so it knows every input and output.
    • 
  

  Status codes: 200 = ok. 400 = bad input. 401 = not logged in. 404 = not found. 207 = a batch with mixed results. 500 = our bug or an unknown error.
