The rule to remember: verify the signature, save the event id, answer 200 fast, do the real work later, and make the work safe to repeat.
  
    
    
  • Webhook: another service calls your URL when something happens.
    • 
    
  • Signature: a code made from the message and a shared secret. Only the real sender can make it.
    • 
    
  • Idempotent: doing it twice has the same result as doing it once.
    • 
    
  • Idempotency key: a unique id for one action, so you can spot a repeat.
    • 
  

  Status codes: 200 = got it, stop retrying (also for repeats). 400 = refused (bad signature or body). 5xx = we failed, please try again.
