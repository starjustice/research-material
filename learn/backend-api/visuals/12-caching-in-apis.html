The rule to remember: a cache buys speed and pays with old data. Decide how old is fine, delete the copy when the data changes, and never share a copy of private data.
  
    
    
  • Cache: a saved copy of an answer, so you do not repeat the slow work.
    • 
    
  • TTL: how many seconds the copy is trusted.
    • 
    
  • ETag: a short tag for one version of an answer. Same tag, nothing changed.
    • 
    
  • Cache-aside: check the cache first. On a miss, ask the database and save the result.
    • 
  

  Headers: max-age=60 = fresh for 60 s. private = only the user's own browser may save it. no-store = do not save it at all. 304 = not changed, keep your copy.
