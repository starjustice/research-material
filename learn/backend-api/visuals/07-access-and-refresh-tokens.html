The rule to remember: the access token is used on every request and ends fast. The refresh token is used rarely, lives in the database, and works once.
  
    
    
  • Access token: a short JWT (about 15 minutes) that you send with every request.
    • 
    
  • Refresh token: a long random string (about 7 days) that you send only to get a new pair of tokens.
    • 
    
  • Rotation: each time you use a refresh token, the server marks it used and gives you a new one.
    • 
    
  • HttpOnly cookie: a cookie that JavaScript on the page cannot read. A good place for the refresh token on the web.
