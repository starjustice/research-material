The rule to remember: DFS goes deep first and uses a stack (the call stack). BFS goes level by level and uses a queue. The three DFS orders differ only in when the node is visited.

    
Words on this page:

    
    
      
  • Root: the top node.
    • 
      
  • Leaf: a node with no children.
    • 
      
  • DFS: depth first: go down as far as you can, then back up.
    • 
      
  • BFS: breadth first: visit level by level.
