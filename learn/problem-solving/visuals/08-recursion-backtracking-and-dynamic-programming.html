The rule to remember: Dynamic programming remembers small answers so they are never solved twice. Backtracking tries a choice, goes deeper, then undoes it and tries the next.

    
Words on this page:

    
    
      
  • Recursion: a function that calls itself on a smaller problem.
    • 
      
  • Memoization: remember the answer to a call so the next identical call is free.
    • 
      
  • DP table: an array of answers to small problems, filled from small to big.
    • 
      
  • Backtracking: choose, explore, undo.
