The rule to remember: A hash map turns a key into a bucket number, so it can jump to the right place. "Have I seen this before?" costs about one step.

    
Words on this page:

    
    
      
  • Hash function: turns a key (like a word) into a number.
    • 
      
  • Bucket: one slot of the table. The key's number picks the bucket.
    • 
      
  • Collision: two keys that land in the same bucket.
    • 
      
  • Map: the JavaScript hash map: key → value.
